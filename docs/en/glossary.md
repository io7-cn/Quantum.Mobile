# Engineering glossary

[简体中文](../zh-CN/glossary.md)

<a id="maui"></a>
## MAUI

Multi-platform App UI, the .NET native application framework.

<a id="sdk"></a>
## SDK

Software Development Kit, the published interfaces and tools used to build plugins.

<a id="rpc"></a>
## RPC

Remote Procedure Call, a structured request to an operation in another process.

<a id="json"></a>
## JSON

JavaScript Object Notation, the text format used for structured messages.

<a id="ci"></a>
## CI

Continuous Integration, automated checks triggered by repository changes.

<a id="apk"></a>
## APK

Android Package, an installable Android application archive.

<a id="pcm"></a>
## PCM

Pulse Code Modulation, uncompressed sampled audio used by the recorder.

<a id="sha256"></a>
## SHA-256

Secure Hash Algorithm with a 256-bit digest, used to detect altered bytes.

<a id="loopback"></a>
## Loopback

The local device network interface, such as 127.0.0.1.

<a id="outbox"></a>
## Outbox

A durable record of an unsent or unconfirmed action, retried with the same identifier.

<a id="secure-storage"></a>
## Secure storage

Operating-system protected application storage for credentials and sensitive state.

<a id="http"></a>
## HTTP

Hypertext Transfer Protocol, used by the local debug request interface.

<a id="nof"></a>
## NOF

The .NET framework used by Quantum for operation contracts and JSON remote calls.

<a id="ui"></a>
## UI

User Interface, the controls and screens used to operate the app.
