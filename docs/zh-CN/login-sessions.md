# 登录会话

[English](../en/login-sessions.md)

桌面端和 Quantum Mobile 采用一致的登录会话机制。当平台支持 `RefreshLogin` 时，密码登录成功后会将完整会话保存到操作系统[安全存储](glossary.md#secure-storage)，并按平台地址区分；密码本身不会保存。应用重启后恢复会话，回到前台时使用新凭据重新连接。

客户端会在访问令牌过期前刷新，并发请求共享一次刷新。明确的 HTTP 401 或平台 `authentication_required` 响应可以触发一次刷新及重试。网络超时或执行结果未知的业务操作不会自动重试。临时断网保留登录，刷新凭据无效、被撤销或过期时清除会话并提示重新登录。

刷新凭据每次使用后轮换，会话最长 30 天。客户端在发送前将刷新请求 ID 写入安全存储，丢失响应后可在平台两分钟的重试窗口内找回最新凭据。超过窗口且轮换结果未知时需重新登录。退出登录先清除本地凭据，并尝试在五秒内撤销服务端会话。离线退出无法即时撤销远端凭据。重置密码或撤销会话会使新版会话绑定的访问和刷新凭据失效。

同一平台账号授权移动访问，无需单独批准设备。设备注册凭据在 24 小时不活跃后过期，经认证的请求会延续有效期。正常关闭桌面保留注册。凭据过期或被撤销时提示重连，换设备后可用同一账号重连；重连不会重做执行结果未知的待处理动作。
