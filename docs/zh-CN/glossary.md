# 工程术语

[English](../en/glossary.md)

<a id="maui"></a>
## MAUI

Multi-platform App UI，.NET 跨平台原生应用框架。

<a id="sdk"></a>
## SDK

Software Development Kit，软件开发工具包，提供插件开发接口与工具。

<a id="rpc"></a>
## RPC

Remote Procedure Call，远程过程调用，以结构化请求调用另一进程中的操作。

<a id="json"></a>
## JSON

JavaScript Object Notation，用于结构化消息的文本格式。

<a id="ci"></a>
## CI

Continuous Integration，持续集成，仓库改动触发的自动检查。

<a id="apk"></a>
## APK

Android Package，Android 应用安装包。

<a id="pcm"></a>
## PCM

Pulse Code Modulation，脉冲编码调制，本应用录音采用的未压缩采样音频。

<a id="sha256"></a>
## SHA-256

256 位安全散列算法，通过摘要检测字节内容变化。

<a id="loopback"></a>
## Loopback

回环网络接口，仅表示本设备，例如 127.0.0.1。

<a id="outbox"></a>
## Outbox

发件箱，持久记录待发送或待确认操作，重试沿用原标识。

<a id="secure-storage"></a>
## Secure storage

安全存储，操作系统保护的应用存储，用于凭据及敏感状态。

<a id="http"></a>
## HTTP

Hypertext Transfer Protocol，超文本传输协议，本地调试请求使用的网络协议。

<a id="nof"></a>
## NOF

Quantum 使用的 .NET 框架，提供操作契约和 JSON 远程调用。

<a id="ui"></a>
## UI

User Interface，用户界面，包括操作应用的控件与页面。

<a id="pkcs12"></a>
## PKCS12

Public-Key Cryptography Standards #12，公钥密码标准第 12 号，以密码保护签名私钥及其证书的容器。Base64 将其字节编码为文本以便注入 Secrets；base64 本身不提供加密。
